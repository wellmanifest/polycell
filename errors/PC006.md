# PC006 — Invalid process definition or dependency order

- **Severity**: ERROR
- **Producer**: `standard/conformance.py`
- **Reference**: [`docs/SPEC.md`](../docs/SPEC.md)

## Meaning

A process contract violates composition constraints: references an unknown cell URN,
declares steps with invalid dependency ordering, embeds a transport address directly in
the process definition, or performs a mutating cell call inside a `query` process.

## Inspection

Run `python3 standard/conformance.py --root .` to locate the offending process file and
constraint failure.

## Remediation

Reference valid cell URNs, fix topological step ordering, remove transport endpoints from
process definitions, and ensure `query` processes invoke only non-mutating cells.
