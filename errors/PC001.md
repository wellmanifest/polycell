# PC001 — Invalid cell contract

- **Severity**: ERROR
- **Producer**: `standard/conformance.py`
- **Reference**: [`docs/SPEC.md`](../docs/SPEC.md)

## Meaning

A cell contract fails validation: invalid contract schema, missing or malformed URN,
missing owner, invalid declared effects, or reference to an unknown type.

## Inspection

Run `python3 standard/conformance.py --root .` from the repository root to report the
exact cell contract path and field failure.

## Remediation

Fix the cell contract YAML/definition fields (schema, URN, owner, effects, and declared
type definitions) so conformance passes cleanly.
