# PC005 — Missing contract examples

- **Severity**: WARNING
- **Producer**: `standard/conformance.py`
- **Reference**: [`docs/SPEC.md`](../docs/SPEC.md)

## Meaning

A cell contract defines no golden `examples`, meaning generated contract tests do not
have behavioral fixture coverage for that cell.

## Inspection

Run `python3 standard/conformance.py --root .` to inspect emitted `PC005` warnings.

## Remediation

Add valid input/output examples to the cell contract, regenerate test artifacts, and
verify with the unit test suite (`python3 -m unittest discover -s tests -p 'test_*.py'`).
