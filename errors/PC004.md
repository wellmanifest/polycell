# PC004 — Orphan cell implementation

- **Severity**: ERROR
- **Producer**: `standard/conformance.py`
- **Reference**: [`docs/SPEC.md`](../docs/SPEC.md)

## Meaning

A cell implementation file exists on disk without a corresponding active cell contract
(dead or unreferenced cell implementation code).

## Inspection

Run `python3 standard/conformance.py --root .` to list orphan implementation paths.

## Remediation

Either remove the obsolete orphan implementation file or restore/register its matching
cell contract, then re-run generation and conformance checks.
