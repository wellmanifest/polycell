# PC002 — Duplicate URN or conflicting type definition

- **Severity**: ERROR
- **Producer**: `standard/conformance.py`
- **Reference**: [`docs/SPEC.md`](../docs/SPEC.md)

## Meaning

Two or more contracts declare the same URN, or multiple definitions share a type name
with conflicting field/schema definitions.

## Inspection

Run `python3 standard/conformance.py --root .` to identify the duplicate URN or
conflicting type definitions.

## Remediation

Ensure every cell and process URN is unique (including explicit major version aliases
where applicable) and unify or disambiguate any conflicting shared type definitions.
