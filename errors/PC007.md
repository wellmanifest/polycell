# PC007 — Stale generated artifacts or missing gen/registry.json

- **Severity**: ERROR
- **Producer**: `standard/conformance.py`
- **Reference**: [`docs/SPEC.md`](../docs/SPEC.md)

## Meaning

Generated artifacts (schemas, protos, generated test cases, or `gen/registry.json`) are
missing or no longer match the current cell and process contracts.

## Inspection

Run `python3 standard/conformance.py --root .` to see missing or out-of-date generated
artifact diagnostics.

## Remediation

Run artifact generation (`make gen` or `python3 tools/polycell/gen.py`) and commit the
updated generated outputs alongside the contract changes.
