# PC009 — Superseded legacy code still present

- **Severity**: WARNING
- **Producer**: `standard/conformance.py`
- **Reference**: [`docs/SPEC.md`](../docs/SPEC.md)

## Meaning

Legacy/replaced implementation code flagged by contracts remains in the workspace even though
a replacement cell or version is active.

## Inspection

Run `python3 standard/conformance.py --root .` to view `PC009` deprecation warnings.

## Remediation

Clean up the superseded legacy code once callers no longer depend on it and update contracts
and generated artifacts accordingly.
